# Privacy policy — Nova Glucose

*Last updated: 1 November 2026*

Nova Glucose is a private family app. It has no server of its own and does not sell, share or analyse your data.

## What the app stores
- Glucose readings, meals, carbohydrate counts, meal photos, insulin doses entered by the family, alerts and settings.
- These are stored **on the phone**, and in the folders the user chooses: the phone's Download/NovaGlucose folder and,
  if turned on, the user's own Google Drive.

## Google Drive
- If the user connects Google Drive, the app asks only for the `drive.file` permission: it can see and change **only
  the files it creates itself** (in My Drive › NovaGlucose). It cannot read any other file in the user's Drive.
- Files are uploaded to the user's own Drive account. Nobody else receives them.
- The user can disconnect at any time in the app (Settings › Google Drive backup) or at
  https://myaccount.google.com/permissions.

## Other services the app talks to
- **LibreLinkUp (Abbott)**: to read the glucose readings, with the user's own LibreLinkUp login.
- **AI services chosen by the user** (Google Gemini, OpenAI ChatGPT or Anthropic Claude): meal photos and questions
  are sent with the user's own API key only when the user asks for a carb estimate or food ideas.

## Security
- Passwords and API keys are encrypted on the phone. Backups lock them with a password chosen by the user.

## Children
- The app is used by a parent to help manage his child's diabetes. No data is shared with third parties.
